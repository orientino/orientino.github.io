## Simple Academic Webpage

Simple academic webpage hosted on GitHub Pages.

### Setup

1. Replace `profile.jpg` with your actual profile photo
2. Update the content in `index.html` with your information
3. Update social media links in `index.html`

### Deploy to GitHub Pages

1. Create a repository named `yourusername.github.io` on GitHub
2. Initialize git and push:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/yourusername/yourusername.github.io.git
   git push -u origin main
   ```
3. Your site will be available at `https://yourusername.github.io`
