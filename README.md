## Simple Academic Webpage

The simplest template with only two small files: `index.html` (<50 LOC) and `styles.css` (<100 LOC). Mobile-friendly, no dependencies, and no bullshit. 

### Setup

1. Fork it and rename it to `yourusername.github.io`
2. Enable the [automatic deployment](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site#publishing-from-a-branch) when there is a new commit
3. `https://yourusername.github.io` will be online after a few minutes
